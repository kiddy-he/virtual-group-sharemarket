# 迁移与独立版差异

来源为 MIT 许可的 `astrbot_plugin_sharemarket` 及聊天宿主内的扩展实现。保留原 Python 导入命名空间，Python 分发名为 `virtual-group-sharemarket`。

| 原宿主内容 | 独立版 |
| --- | --- |
| 生产运行配置、账户和数据库 | 不迁入；从合成示例新建市场 |
| 角色帮助图与私有素材 | 通用 Pillow 帮助卡，无外部人物素材 |
| OneBot/OpenClaw 权限和路由 | 独立 SDK 的上下文验证、群市场绑定；宿主负责平台身份真实性 |
| 群人设、记忆、工作区读取 | 移除；可注入 personaName / request，不读宿主记忆 |
| 统一投递队列和定时播报 | 未迁入；仅提供 outbox 与 ACK、新闻预生成器 |
| 聊天主模型与 fallback | 未迁入；可选配置化 JSON 文本适配器 |
| 自动分析 agent | `query.analyze` 只给只读业务数据，由宿主决定是否追加分析 |
| 赛季、每日任务和加速卡 | 不对外开放；部分旧模块为兼容保留 |

现有生产系统继续使用原目录和服务。提取和发布本项目不应修改原系统开关、不恢复暂停市场、不复制用户数据。不要在两个实现间共享活动 SQLite 文件。

未来方向包括正式宿主插件包、更多平台驱动、配置 schema 和更细的交易接口合同、日历更新机制及更大范围性能测试。未实现事项不应作为已有功能宣传。
