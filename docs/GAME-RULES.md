# 游戏规则

全部资金及证券都是游戏数值。规则最终以当前市场配置和返回结果为准。

## 基础交易

先开户获得配置的初始虚拟资金；股票代码、行业和名称可先用搜索确认。买入按整手约束，卖出受持仓和可卖数量约束；T+1、费用、涨跌停、停牌、集合竞价及限价均由引擎处理。一次请求可全部成交、部分成交、排队或拒绝，不能把成功创建委托解释为全部成交。

可用资金、冻结资金、可取资金、待结算资金分别管理。下单冻结资源，撤单退还未成交部分；手续费和税费影响实收。交易服务使用整数分与合法数量验证，并保留审计记录。

## 查询

行情总览按行业/类别拆成多页图片，每页都应发送。K 线为日 OHLC，最多约 21 个历史交易日加当日未收盘记录；没有历史时使用已有盘中数据，不伪造历史。个股范围不明确时先搜索；读操作可返回候选，交易不能根据模糊名称猜测对象和数量。

资金、持仓、委托、成交、自选等个人信息应私聊投递。群排行只展示业务允许的公开排名，不发送全部账户原始数据。

## 因果市场

盘中每 tick 可变化，不是每天只跳一次。宏观、行业、经营、公开信息、风险偏好、流动性、交易和随机创新共同影响价格。事件可能有预告、传闻、确认、失败、落地等阶段，但并非每个突发事件都提前预告，也不是一个标题固定对应涨跌幅。

公开快讯与隐藏真值分离，查询不会给出未来结果。模拟新闻必须保留虚拟标识；事件报道不是收益承诺。模型只是游戏近似，没有复刻所有现实市场机制，见 [模型设计](MODEL-DESIGN.md)。

## 扩展玩法

IPO 认购及发行需满足服务中的价格、股数、额度和期限要求；融资借款和融券依赖有限资金、证券库存及担保约束。利息、分红、还券、强平和公司退出会影响净资产。流动性不足时可能无法立刻清偿，负净资产可冻结等待核账。道具、签到、成就受开关及实际服务规则约束。

每日任务、赛季奖励和加速卡已下线。不要因为包内有兼容代码而向用户宣传这些功能可用。
