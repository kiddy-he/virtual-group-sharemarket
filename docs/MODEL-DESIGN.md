# 虚拟群股市 causal-v2.1 最终实现设计

模型设计基线：2026-11-02；独立提取说明更新：2026-11-05。本文件描述当前算法的实现合同。测试方法与可复现边界见 [TESTING.md](TESTING.md)。虚拟公司新闻不代表真实上市公司公告。

## 目标与边界

在独立的 `/fx` 交易、资金账户、T+1 与竞价内核上，配合宿主权限与投递形成短期交易噪声、中期预期变化、长期经营与退出交叉驱动的虚拟市场。所有增长、事件强度、波动、财务与发行期限采用同一虚拟日时钟；3秒一tick、1200秒一虚拟日的现有节奏不变。年度统计按252虚拟日计算，新闻限频按现实时间计算。

采用生产和研究共用的数值核心；生产的真实玩家/NPC订单使用SQL账本与有限做市商，背景机构使用两个有现金和股份的聚合账户。背景机构不是逐笔完整交易所订单簿，算法不能宣称已经复刻现实市场。不得将历史校准范围有限的游戏参数解释为投资预测。

## 本次补充的现实影响路径

| 因素 | 算法落实 | 不作的过度解释 |
|---|---|---|
| 利率、信用、期限与偿债 | 利率影响债务成本与估值折现；信用收紧限制融资；公司有偿债到期日 | 未构建独立债券市场和完整收益率曲线 |
| 工资、物流、原料、汇率 | 企业异质进口/出口、成本暴露与提价能力进入毛利和收入 | 非实际商品期货或外汇行情 |
| 行业景气和竞争 | 市场、行业、公司创新与竞争网络；研发影响未来经营 | 行业弹性为游戏参数，非实证估计 |
| 报告滞后与数据修订 | 隐藏经营与公共财报分离，错峰财报、宏观测量误差和修订 | 不允许背景投资者直接读取未来经营结果 |
| 现金周转与财务困境 | 应收、库存、应付、固定资产、现金、债务、税负和折旧；现金违约累计 | 不包含每种现实会计准则和银行资本监管规则 |
| 银行差异 | 银行类使用账面权益/盈利混合估值与信用损失准备 | 不代表完整银行资产负债模拟 |
| 股本、限售与资金流 | 实际IPO股数/募集现金、分红除息、限售解禁、季末被动调仓 | 没有完整期权做市、ETF份额和跨境套利市场 |
| 融资与融券 | 有限贷款资金和可借库存，卖空负债，利息、担保线、真实流动性强平 | 流动性不足时保留债务，不凭空清偿 |
| 事件预期与条款 | 合同、研发、收购、治理、再融资、供应事件的证据和成败分支 | 公告不是固定正负收益指令 |
| 灾害和网络风险 | 气候/网络风险暴露影响突发事件的概率和规模 | 不为每个灾害制造必然提前预告 |
| 客户、供应商、竞争者 | 带根事件ID的权重传导，有限且衰减 | 不是完整投入产出表或信用挤兑网络 |
| 拥挤、流动性、估值久期 | 状态相关波动、深度、临时流量衰减、公共估值差分、卖空拥挤 | 残差噪声不冒充某个已知经济因素 |

原提案中的资本质押、逐品种能源库存、独立外币债务/套保、细分税率政策、期权Gamma、完整交叉持股/信用网络并未分别设置独立市场。首版将其可观察作用压缩进相关成本、融资、风险和网络通道；不得说每个候选字段均已单独实现。增加字段必须有明确新增因果路径，避免一个冲击多次计价。

## 信息层与时序

1. 隐藏真实层：企业经营、未披露项目真值、现金、债务、事件分支。
2. 公共层：已发布宏观估计/修订、财报、公开日历、事件概率和阶段、最终条款。
3. 交易层：公共估值、价值/趋势/事件/流动性信号、成交深度和风险预算。

数值引擎只从公共信息形成估值。发布记录带 `published_tick`、`effective_tick`、虚拟日、阶段和根事件ID；公共估值更新最早晚于发布两个tick。公共查询序列持久化，不返回随机种子、隐藏真值、未公布现金或未来结果。独立版新闻改写只获取公开快讯和配置的角色名称，不读取群/私聊历史。宿主限频投递与经济仿真解耦，不能保证每个群都在信息生效前收到快讯；所有人均可经 `/fx 新闻`、RPC `query.event` 查询公开记录。

## 数学与状态推进

`market/causal_state.py` 定义12维宏观状态：需求、通胀、利率、信用、汇率、原料、外需、不确定性、被动资金、地缘风险、工资、物流。稳定的一阶持续状态加有限创新，需求/通胀/利率/信用/物流含滞后传导，状态有界。行业过程受需求和融资条件影响；公司根据出口/进口、原料、定价权、研发、治理、杠杆等暴露产生不同响应。

企业逐日销售=年化收入/252；毛利扣除折旧、利息与税负，银行另计信用损失准备。营运资金和资本支出转移现金与资产，始终重算 `资产=现金+库存+应收+固定资产`、`权益=资产-债务-应付`。账目金额允许分币舍入误差；不能将账面利润直接当现金。分红仅在实际权益、公开账面权益与公开现金流均为正时发放，同时保留必要现金，单季支付不得超过报价/公开估值较低者高于最小价位部分的10%；虚拟日标记保证同日重复结算不重复分红。低价/困境企业留存现金，避免一分钱股票持续收到多分钱股息。

非银行公共价值采用受约束的现金流增长估值：FCF×(1+g)/(r-g)，g和r有边界且差至少3.5个百分点；加净现金与有限事件现值。银行使用经营账面价值与受限盈利的组合，再加净现金。初始尺度仅校准一次到开盘价。该公式是受约束的增长永续近似，不是显式逐期有限DCF。

公共信息变动先作部分即时反应，余下的公共价值差缓慢纠偏；临时流量按状态变化进入价格，撤单/衰减不会重复增加永久漂移。波动由市场/行业/个股共享创新、随机波动与多日实现波动共同决定，非强制周期。余项为97.5%标准正态+2.5%三倍标准差正态混合，按sqrt(1.2)标准化，有限方差；扩散按sqrt(虚拟日dt)缩放。

报价中心形成后，两个背景机构只有能交换整数股且买方现金足够时才成交，成交额按整数分结算，无成交时不伪造成交量。用户/NPC有限做市商分别使用独立资金/持股与盘口深度；买卖围绕参考中价，不能利用“上次买入价继续作为中价”逐单推高报价。集合竞价仍采用最大可成交量定价的玩家订单匹配。

## 事件机制

`market/causal_events.py` 负责条件事件强度、传闻/进展、证据似然的Bayes更新、延期、最终条款和现金兑现。再融资/治理等事件概率受企业状况影响。成功不必然是利好：若最终条件差于已有预期，公开期望值可以下降。

每个根事件保存剩余价值与已兑现现金。随着合同等兑现，剩余价值下降，实际现金进入账目，不能把同一笔现金流同时计为额外永久利润和新闻冲击。网络上的相关企业按权重受影响，不复制完整根公司涨幅。有限持续时间、冷却与退出清理阻止事件无限累积。

财报、宏观修订、偿债日历、解禁和调仓是时钟事件，不由每日随机标题数量替代。突发事件允许无预告；重要清算使用已披露负权益、持续现金违约、三日准备期和债权优先后的残值，回收可为零。公司退出后停止经营、停止新增事件并退回剩余可归属资产，不把价格下限当保底赔偿。

## 交易、资本与恢复

初始每公司1000万股分配为：两个背景机构各100万，用户侧做市商100万，借券池50万，锁定库存650万。玩家/NPC初始无持仓；迁移时已有持仓从锁定库存扣除。卖空只转移实际可借股份，另记录待还证券。新股按实际发行量重新分配可用库存，实际认购股份与募集现金入账。

借款扣有限贷款机构现金，还款/实付利息归还机构，V2年利率统一按252个虚拟日折算，部分还券后按剩余借券金额计费；借券卖出由有限做市商买入，买回由做市商卖出归还证券池；每tick信用设施的总深度有限。分红权益、融券代付红利和公司清算结转进入账本。强平取消挂单、豁免T+1但仍执行实际撮合/费用/涨跌停/停牌和资金约束。未成交或未偿还部分保留；负净资产冻结并等待核账。

业务动作共用可重入锁、SQL事务、内存快照回滚和JSON检查点。NumPy数组按有限dtype白名单恢复，禁止pickle/动态类导入。同一操作ID不重复交易；重启保留资金、股份、订单、事件和随机流位置。随机流按公司代码/阶段/计数器分离，不因数组重排或增加新股改变旧公司的创新序列；生产seed随机生成且不公开。

IPO创建写入 `close_day=当前虚拟日+1`，日终按虚拟日到期，兼容旧发行记录的现实时间截止。企业上市时间、到期日和待公布数组在扩容时同时扩充，不重置已有公司。

## 独立版新闻与宿主职责

`sdk/news-producer.mjs` 读取公开 feed，构造具体事件报道并保存到新闻 SQLite。查询通过 `readPreparedMarketNews()` 直接读取缓存，不在用户查询路径临时请求模型。可选模型与角色由配置/注入提供，不读取原 bot 的 SOUL 或聊天记忆。

自动播报、群限频、最近聊天避让、热配置撤权和平台回执由宿主实现。原集成版的统一投递队列与常驻新闻 worker 没有迁入，本版不能单独完成群消息自动发布。

## 验证边界

设计关注有限正价、现金与股份守恒、会计一致性、合理日波动与回撤、行业相关性、波动聚集、流动性及公开信息因果顺序。统计门槛只用于游戏行为验收，不能解释为真实股票预测能力。

历史集成阶段曾做多种子长线测试及 SQL 恢复验证；其原始报告和数据未进入本公开仓库，不作为本次重新运行的证据。本次可复现实测以 TESTING.md / VALIDATION.md 及测试脚本为准。轻量数值仿真不能替代带 SQL、玩家订单和平台投递的完整长期验收。

## 文件映射

路径相对于 `src/astrbot_plugin_sharemarket/`：

- 数值世界、随机流、经营、估值、机构成交：`market/causal_state.py`。
- 事件状态机与公共记录：`market/causal_events.py`。
- 行情兼容适配与发行股本：`market/causal_engine.py`。
- 公开字段与日历：`market/causal_public.py`、`market/calendar.py`。
- 分红、风险警示与清算：`game/causal_corporate.py`。
- 有限信用交易：`game/causal_margin.py`、`game/margin.py`。
- SQL 交易、检查点、日结、发行：`game/trade.py`、`game/recovery.py`、`game/dayclose.py`、`game/ipo.py`。
- 独立身份与群绑定：仓库根目录的 `sdk/adapter.mjs`；实际平台发送由宿主提供。
