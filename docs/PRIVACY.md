# 隐私与公开发布

## 不包含的内容

生产账号、群号、私聊/群聊历史、人设记忆、供应商密钥、内部服务域名、代理地址、私有配置、日志、数据库、备份、socket、随机种子和恢复检查点均不属于公开仓库内容。示例的 `700000001/700000101` 等号码是合成占位符，`example.invalid` 为不可调用示例域名。

保留的版权与公开 GitHub 账号是项目归属信息。提交作者使用 GitHub noreply 邮箱，不使用真实个人邮箱。帮助图由代码绘制，未分发原人物参考图或生成图。

## 发布流程

- 新目录和全新 Git 历史，只加入经审查的源码、测试、文档和合成示例。
- `.gitignore` 忽略 state、环境文件、数据库、日志和密钥文件；忽略规则不能移除已经追踪的文件。
- `scripts/audit-public.py` 检查 Git 追踪文件（未初始化时检查公开路径白名单），阻止常见密钥、个人邮箱、私有 URL、非示例数值账号、数据库和私有二进制文件。
- 本地额外使用已知生产凭据、账号及域名作精确匹配，值不写入报告和仓库；这是本次发布的本机检查，不是公共脚本内置列表。
- 检查 wheel / sdist 内容，防止打包时额外引入私有文件；推送前审查 staged diff 和全部提交历史。

模式扫描和已知值匹配不能证明对所有未知隐私形式的绝对检测。新增文件或开放 PR 后仍需人工审核，不要将本地敏感数据复制进测试 fixture。

## 运行后

state 与日志会产生真实用户 ID 和隐藏世界信息。分享问题时先创建合成最小复现，不上传完整数据库。意外泄露应立即撤销/轮换凭据，停止传播后清理历史，删除 HEAD 文件不能消除旧提交风险。
